# Invitație de botez

Acesta proiect este baza unei invitații online pentru botezul unei fetite, în stil elegant și cald, cu design în tonuri pastelate. În acest stadiu este doar structura inițială a aplicației, fără componente de invitație încă implementate.

## Cum rulezi proiectul

1. Instalează dependențele:
   npm install
2. Pornește serverul de dezvoltare:
   npm run dev
3. Construiește versiunea de producție:
   npm run build

## Tehnologii

- React + Vite
- JavaScript
- Framer Motion
- Netlify pentru deploy-ul viitor
